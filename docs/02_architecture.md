## 2. 芯片角色与职责分配 (MCU Roles & Responsibilities)

### 2.1 主控核心板 (ESP32-C6)
* **网络与协议栈：** 负责 Matter over Thread 协议栈的常驻与维护，处理来自 Home Assistant (HA) 等边界路由器的控制指令。
* **业务逻辑中心：** 独立运行温控闭环算法（对比目标温度与当前温度），直接驱动**继电器 GPIO**。
* **时间管理中心：** 利用内置 RTC 和网络 NTP 同步，本地死守定时开关机、最大 5 小时延时关机等时间敏感型任务。
* **数据采集：** 直接连接 **DHT11 温湿度传感器**，获取第一手环境数据。

### 2.2 用户交互板 (ESP32 / ESP32-S3)
* **图形渲染：** 运行 **LVGL** 框架，驱动 2.8寸 (320*240) 电阻液晶屏，负责时钟、天气预报及温度曲线的绘制。
* **输入捕获：** 实时扫描方向键（温度加减）、返回键、电源键以及电阻屏的坐标输入。
* **物理反馈：** 接收到有效按键输入时，控制**蜂鸣器**发出提示音。

## 3. 硬件外设与通信接口设计 (Hardware Interface Design)

### 3.1 跨板通信接口 (Inter-Board Communication)
* **物理层：** 双线异步串口 (UART)。
* **配置参数：** 波特率 115200bps，8位数据位，1位停止位，无奇偶校验。
* **数据流向示例：**
  * `Core -> UI`: 发送当前室内温度、湿度、加热器当前工作状态、系统时间。
  * `UI -> Core`: 发送用户修改后的目标设定温度、定时/延时开机触发指令、手动开关机指令。

### 3.2 外设引脚分配预留 (GPIO Allocation Planning)
*(具体引脚编号将在下一步接口细化阶段敲定)*
* **ESP32-C6 侧：** DHT11 数据引脚 (1ch)、继电器控制引脚 (1ch)、UART_TX/RX (2ch)。
* **交互板侧：** 屏幕 SPI 总线 (4-5ch)、电阻触摸屏 SPI/I2C (3-4ch)、方向/返回/电源物理按键 (3-5ch)、蜂鸣器 PWM 引脚 (1ch)、UART_TX/RX (2ch)。

## 4. 可靠性与容错设计 (Fail-Safe & Autonomy Design)
* **通信丢失保护：** 主控核心板 (C6) 内置看门狗机制监测与交互板的 UART 通信。若交互板意外死机或通信中断，C6 将按照上一次有效的设定温度继续执行本地温控和定时逻辑，确保供暖系统不受影响。
