# 功能需求说明书 (Functional Requirements Specification)

## 1. 项目概述 (Project Overview)
本项目旨在开发一款基于 ESP32 芯片、支持 Matter 协议（通过 Thread 无线技术）的智能温控器。该设备具备本地 LCD 屏幕交互及物理按键控制，能够无缝接入 Home Assistant (HA) 等主流智能家居平台。产品核心设计理念是**“网络智能扩展，本地绝对可靠”**，确保在断网或无网络环境下，基础的温控逻辑、定时和延时功能仍能百分之百本地正常运行。

## 2. 硬件与外设需求 (Hardware & Peripherals Requirements)
* **核心微控制器：** ESP32 系列芯片（支持 Thread/BLE 协议，具体 variant 待架构设计阶段确认）。
* **显示屏：** 2.8寸液晶屏（分辨率 320*240），带电阻式触摸层。
* **物理输入界面：** 鉴于电阻屏触感限制，必须配备物理交互按键，包括：
  * 方向键 / 温度加减键（具体形式如五向摇杆、旋转编码器或独立微动按键待定）。
  * 返回键 (Return/Back Key)。
  * 电源键 (Power Key)。
* **执行机构：** 1路继电器（Relay），用于控制加热器（Heater）控制线的导通与断开。
* **环境传感器：** DHT11 温湿度传感器，用于实时采集室内环境温度与湿度。
* **提示音效：** 集成 1 个蜂鸣器，用于提供按键操作及系统状态的物理声音反馈。

## 3. 功能需求细则 (Functional Requirements)

### 3.1 核心温控与本地运行 (Core Thermostat & Local Autonomy)
* **本地闭环控制：** 设备必须根据 DHT11 采集到的实时温度与用户设定的目标温度，本地自主控制继电器的开合（导通=开启加热，断开=关闭加热）。
* **断网保护（边缘计算）：** 设备的温控核心逻辑、定时任务、延时任务必须完全运行在本地 MCU 上。断网或未配网状态下，除网络上报和天气显示外，所有本地控制、屏幕显示和按键交互均不受任何影响。

### 3.2 智能互联 (Smart Connectivity)
* **Matter 协议支持：** 采用 Thread 作为网络传输层，通过 BLE 进行蓝牙配网。
* **生态兼容：** 必须能够稳定接入支持 Matter 的生态系统，以 Home Assistant (HA) 为首要对接目标。
* **属性映射：** 需将本地温度、湿度、继电器状态以及目标温度映射为 Matter 标准 Cluster 属性，支持双向同步。

### 3.3 本地定时与延时功能 (Scheduling & Timers)
* **定时开关机：** 支持用户设定特定时间段进行加热器的自动开启与关闭。
* **延时关机：** 支持倒计时关机功能，最大延时时长为 5 小时。

### 3.4 UI 界面与信息显示 (User Interface & Display)
* **GUI 框架：** 采用 LVGL 图形库进行 320*240 分辨率的界面开发。
* **时钟显示：** 屏幕常驻显示当前时间。
* **天气预报：** 在屏幕空间允许且网络连接正常的条件下，支持从网络获取并显示当地当天的天气预报。
