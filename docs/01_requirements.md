# ESP32-C6 Matter 温控器需求规格说明书

## 1. 项目概述

本项目基于 ESP32-C6 单芯片方案实现一款标准的 Wi-Fi + Matter 温控器设备。本设备支持本地独立运行与控制，无需依赖网络即可完成基础温控功能；同时作为标准 Matter 设备，可无缝接入 Home Assistant (HAOS) 等智能家居生态系统，将定时开关机、复杂联动等高级功能交由上位系统处理。

---

## 2. 硬件资源配置与引脚分配

| 硬件模块 | 型号/类型 | 连接引脚 (GPIO) | 描述 / 说明 |
| :--- | :--- | :--- | :--- |
| **主控芯片** | ESP32-C6-DEVKITC-1 | - | 板载 Wi-Fi 6 + IEEE 802.15.4 (Matter) |
| **电源/待机按键** | 轻触开关 | GPIO19 | 开关机 / 模式切换按键 |
| **温度加按键** | 轻触开关 | GPIO21 | 设定温度增加按键 / 组合配网按键 |
| **温度减按键** | 轻触开关 | GPIO20 | 设定温度减少按键 / 组合配网按键 |
| **加热器控制** | Relay / Driver | GPIO22 | 高电平：开启加热；低电平：关闭加热 |
| **温度传感器** | DHT11 | GPIO4 | 单总线数字温湿度传感器（采用去抖/滤波算法） |
| **指示灯阵列** | WS2812B RGB LED | GPIO8 | 6 颗级联 RGB LED（LED_1 至 LED_6 串联） |

## 3. 智能设备与网络功能 (Wi-Fi / Matter)

### 3.1 协议支持
* 本设备为标准的 Wi-Fi + Matter 温控器（Matter Thermostat）设备。
* 设备的温度检测值、设定温度值、加热状态及开关状态需同步暴露至 Matter 协议簇（Clusters）。

### 3.2 配网逻辑 (Commissioning Mode)
* **首次上电自动配网**：未绑定网络的设备在首次上电后，自动进入 Matter 配网状态。
* **手动触发配网**：在任何工作状态下，**同时按下“温度加”键 (GPIO21) 与“温度减”键 (GPIO20) 并保持 3 秒**，设备强制重置配网状态并进入 Matter 配网模式。
* **配网指示灯**：进入配网模式后，**LED_1 显示黄色呼吸灯，呼吸周期为 2 秒**。

---

## 4. 按键检测与操作逻辑

### 4.1 通用检测算法
* 所有按键检测必须加入软件去抖动算法，消除机械抖动干扰。
* 支持短按与长按事件检测。

### 4.2 按键功能定义

1. **电源键 (GPIO19)**：
   * **短按 / 长按**：在“待机模式”与“开机模式”之间切换。
2. **温度加键 (GPIO21)**：
   * **开机状态下短按 / 长按**：设定温度增加 1 摄氏度（上限为 21 摄氏度）。
3. **温度减键 (GPIO20)**：
   * **开机状态下短按**：设定温度减少 1 摄氏度（下限为 17 摄氏度）。
   * **开机状态下长按**：设备进入待机模式。
4. **组合键 (GPIO21 + GPIO20)**：
   * **同时长按 3 秒**：触发 Matter 配网模式。
5. **待机唤醒**：
   * 在待机模式下，按下或长按**任意单个按键**，设备立即恢复至开机模式。

## 5. 指示灯阵列与灯效设计

### 5.1 硬件阵列分工与映射
* **LED_1**：温控器状态/配网指示灯。
* **LED_2 ~ LED_6**：当前温度与目标设定温度指示灯。
  * **LED_2**：小于等于 17 摄氏度
  * **LED_3**：18 摄氏度
  * **LED_4**：19 摄氏度
  * **LED_5**：20 摄氏度
  * **LED_6**：大于等于 21 摄氏度

### 5.2 灯效展示规则

#### 1. 上电自检 (POST)
* 上电后，LED_1 至 LED_6 依次点亮 100ms 白色后熄灭，随后进入待机模式（若未配网则进入配网模式）。

#### 2. 配网模式灯效
* **LED_1**：显示黄色呼吸灯，呼吸周期为 2 秒。

#### 3. 开机模式灯效
* **LED_1（加热/状态指示）**：
  * **加热中 (GPIO22 = HIGH)**：循环展示灯效——200ms 橙色 $\rightarrow$ 200ms 红色 $\rightarrow$ 200ms 紫色 $\rightarrow$ 循环。
  * **未加热 (GPIO22 = LOW)**：常亮绿色。
* **LED_2 ~ LED_6（温度指示）**：
  * **小于当前实测温度**的指示灯：常亮绿色。
  * **设定温度**对应的指示灯：
    * 若实测温度 < 设定温度：呼吸显示紫色，呼吸周期为 1 秒。
    * 若实测温度 $\ge$ 设定温度：交替显示绿色和紫色，各切换保持 1 秒。
  * **大于当前实测温度且非设定温度**的指示灯：熄灭。

#### 4. 待机模式灯效
* **待机定义**：软待机（软关机）。内部主控、Matter 协议、Wi-Fi 及温度采集控制逻辑均正常运行，GPIO22 停止加热，LED_2 ~ LED_6 熄灭。
* **LED_1（待机温度呼吸灯）**：根据当前 DHT11 实测温度，以 2 秒为周期进行呼吸显示，颜色映射关系如下：
  * $\le 17$ 摄氏度：蓝色呼吸灯
  * $18$ 摄氏度：青色呼吸灯
  * $19$ 摄氏度：绿色呼吸灯
  * $20$ 摄氏度：黄色呼吸灯
  * $21$ 摄氏度：橙色呼吸灯
  * $22$ 摄氏度：红色呼吸灯
  * $\ge 23$ 摄氏度：紫色呼吸灯

## 6. 温控与采样算法

### 6.1 温度数据去抖与滤波
* DHT11 数据采集需采用数字滤波/去抖动算法（如滑动平均滤波或中值滤波），避免突发噪声引发系统频繁误判。

### 6.2 迟滞温控逻辑 (Hysteresis Control)
* **设定温度限制**：设定温度范围限制在 17 摄氏度 至 21 摄氏度 的整数。
* **动态阈值调整**：为防止加热开关在临界点频繁启停，设置 $\pm 0.5$ 摄氏度 的控制滞后区间。
  * **升温过程**：当加热器处于开启状态时，只有当实测温度上升至 `设定温度 + 0.5 摄氏度` 时，才关闭加热器 (GPIO22 = LOW)。
  * **降温过程**：当加热器处于关闭状态时，只有当实测温度下降至 `设定温度 - 0.5 摄氏度` 时，才重新开启加热器 (GPIO22 = HIGH)。
